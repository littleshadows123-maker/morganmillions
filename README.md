# Morgan Millions

Static site for the Morgan Millions futurity program.

**Live:**
- Primary: [morganmillions.org](https://morganmillions.org)
- Vercel: [morganmillions.vercel.app](https://morganmillions.vercel.app)
- Preview: [morganmillions.pplx.app](https://morganmillions.pplx.app)

## Pages

- `index.html` — home
- `program.html` — the Vault, Bridge, Classes, Governance
- `stallions.html` — Vaulted Sires with editorial modal (shareable via `#seat-NN`)
- `event.html` — event schedule

## Assets

- `assets/css/style.css` — full stylesheet
- `assets/js/site.js` — countdown, nav, scroll reveal, stallion modal
- `assets/img/` — heroes, stallion portraits, favicon

## Deploy

Pushes to `main` auto-deploy via Vercel.
